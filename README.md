# 🔐 Password Manager

A simple command-line Password Manager built with Python.

This project was created as a practice project to apply Python fundamentals such as dictionaries, functions, loops, conditions, modules, and random password generation.

## 🚀 Features

- Add a new account
- Generate a random password
- Show all saved accounts
- Search for an account by email
- Update an account password
- Delete an account
- Colored command-line interface
- Clear terminal screen
- Password generation using letters, digits, and symbols

## 🛠️ Technologies

- Python 3
- Colorama
- Random
- String
- Time
- OS
